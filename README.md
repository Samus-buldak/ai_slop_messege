# Данные для обучения (только с правдивой разметкой авторства)

`dataset.csv`: колонки `text,is_ai,subject` (subject не обязателен).

* `is_ai=1` — текст **сгенерирован ИИ**;
* `is_ai=0` — **написан человеком**;
* **частично ИИ-правленные письма** нельзя безоговорочно маркировать одним классом для всех 4 зон; нужны отдельные метки зон для действительно корректного segment-level обучения.

Или положи сырые `.eml` в `data/human/` и `data/ai/`.

В архиве есть `demo_synthetic.csv` из исходного `repo/ML/data/processed/synthetic_full.csv`.
Это лишь демонстрация технической работы. Для ИИ-классификации нужно выбирать поле `ai_assisted`, НЕ `label` (последнее связано с ham/spam). Шаблонные синтетические тексты из этой таблицы НЕ подтверждают реальные показатели качества. Для реальной проверки нужны новые письма от настоящих авторов и настоящих моделей, отдельно от обучения.

Команды:

```sh
python train.py --csv data/demo_synthetic.csv --offline  # демо офлайн
python train.py --csv data/demo_synthetic.csv            # демо с API, если ключ установлен
python train.py                                           # ваш реальный data/dataset.csv
```

KIRUSHA AI DETECTOR v2.2 — ПОЛНАЯ ВЕРСИЯ ДЛЯ WINDOWS

БЫСТРЫЙ ЗАПУСК:
1. Распакуй ВЕСЬ архив в обычную папку (например, C:\Kirusha). Не запускай BAT прямо из ZIP.
2. Установи Python 3.10+ (если не установлен). Подключение к интернету нужно для установки библиотек и внешнего API.
3. LM Studio: embedding-модель Qwen3 0.6B должна быть загружена и работать на порту 1234, с идентификатором qwen3-embedding-local. При наличии CLI скрипт попробует её запустить сам.
4. Дважды нажми 00_START.bat. Скрипт создаст .venv-local, установит библиотеки, создаст .env и откроет Блокнот.
5. В .env впиши API_KEY=твой_ключ, затем сохрани файл. API_URL и MODEL уже заполнены из старого проекта; если у тебя другой провайдер — замени их тоже.
6. Возвращайся в окно BAT: Enter -> проверка Qwen -> первоначальное обучение с LLM -> проверка сообщений.
7. Для повторного запуска открывай тот же 00_START.bat: обученная модель будет использована без переобучения.

ВАЖНО:
- Весь исходный проект и датасет включены. Новая model_hybrid_qwen обучается при первом запуске, её весов в архиве нет.
- Обучение с LLM-сегментацией отправляет текстовые письма провайдеру из .env; может расходовать квоту/деньги API.
- Проверка картинок требует VISION-совместимой модели. Если MODEL текстовая, добавь VISION_MODEL=имя_модели в .env, при необходимости VISION_API_URL и VISION_API_KEY.
- Изображения отправляются во внешний vision API ТОЛЬКО при наличии фото; если фото нет, вызова vision нет.
- Не передавай .env никому и не коммить API_KEY в Git.
- Анализ не даёт доказанного авторства; вероятность изображений — эвристическая оценка.
